ROG-GL553VD-OpenRGB — Project Status
Project Completed

Development work on ROG-GL553VD-OpenRGB has been completed.
At this stage, the implementation is considered finished, but there is no guarantee that everything works correctly on all devices.

The project is currently experimental and requires additional testing from users who own the hardware.

Current Known Issues

During testing, the following problems were observed:

The laptop LEDs may randomly turn off and back on after applying effects or changes.
The keyboard backlight can completely stop working after testing.
Stability and compatibility are not guaranteed.

Because of this, please use the project at your own risk.

Looking for Testers / Contributors

If you are interested in this project, own an ASUS ROG GL553VD, or would like to help with testing and debugging, please contact me.

Any feedback, logs, or test results are highly appreciated and may help improve stability in the future.

Warning

This software directly interacts with hardware lighting controls.
Improper behavior may temporarily disable keyboard lighting functionality until reboot or reset.

Use carefully.
